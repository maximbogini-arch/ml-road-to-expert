# CS2 Data Analysis

A data analysis project exploring Counter-Strike 2 match statistics across different competitive tiers.

## Project Overview
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Player and team performance analysis
- Statistical visualizations of match data

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
- `CS2_Project.ipynb` — main analysis notebook
- `sample.ipynb` — supplementary notebook
- `archive/` — datasets used in the project

## Getting Started
Open `CS2_Project.ipynb` in Jupyter Notebook or JupyterLab and run the cells to explore the analysis.
